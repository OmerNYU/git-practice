# Software Engineering Article Reflection

## Article

[Why Machine Learning Models Should Be Allowed to Say "I Don't Know"](https://epoch.hashnode.dev/why-machine-learning-models-should-be-allowed-to-say-i-don-t-know)

## Why I Find It Interesting

I find this topic interesting because machine learning systems are often designed to always produce an answer, even when they are uncertain. The article explores why allowing a model to abstain can sometimes make a system more reliable and trustworthy, especially when incorrect predictions can be costly.

I also find the topic interesting from a software engineering perspective because it connects model behavior with system design. Building useful AI systems is not only about maximizing accuracy; it also involves deciding how the system should behave when it does not have enough confidence to make a good prediction.
